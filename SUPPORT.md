# Support

Before opening an issue, check the [Linux support matrix](docs/SUPPORT.md), the [CLI guide](docs/CLI.md), and the [known acceptance limits](docs/ACCEPTANCE_STATUS.md).

Use GitHub Issues for reproducible bugs and feature requests. Do not post proxy credentials, private hostnames, process environments, user logs, or traffic data. Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
