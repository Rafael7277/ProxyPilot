# Community code of conduct

We aim to make participation welcoming and respectful for everyone.

Examples of behavior that support this community include constructive technical feedback, patience with different experience levels, respect for privacy, and clear disagreement about ideas without personal attacks.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, publishing another person's private data, and disruptive or abusive conduct.

Project maintainers may edit or remove contributions that violate this policy. Until a public repository and contact are approved, contact the project owner through the existing private channel to report an issue.
